# 渠道标识来源

这些图片仅用于识别渠道，商标属于各自权利人，不表示其认可或赞助 Corki。
资源随管理页面本地加载，不请求远程图床。

- WhatsApp、Telegram：SVG Logos（CC0），通过 `@iconify-json/logos@1.2.18` 提取原彩色标识，未改变路径与配色。
  https://github.com/gilbarbara/logos
- 微信：Simple Icons（CC0-1.0），通过 `@iconify-json/simple-icons@1.2.101` 提取 WeChat 标识，使用品牌绿色 `#07C160`。
  https://github.com/simple-icons/simple-icons
- 飞书：OpenClaw 的 `extensions/feishu/assets/icon.png`（参考版本 d0916212），原始 PNG 未修改。
  https://github.com/openclaw/openclaw/tree/main/extensions/feishu/assets
  OpenClaw 源代码使用 MIT 许可；品牌标识的商标权仍属于原权利人。
