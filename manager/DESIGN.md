# 管理工作台设计

目标：让本机用户在一分钟内理解当前配置，并能直接完成常用管理操作。
不在页面中制造虚假的在线状态、模拟用量或未接入的索引状态。

## 信息结构

- 主页负责回答「现在用什么、资源有多少、最近发生了什么」。
- 供应商负责连接，模型负责能力参数；两者独立页面、同一嵌套配置来源。
- Skills 按内置、Corki 专属、公共目录分区，提供状态筛选、详情和整包导入；知识库与记忆保留文档卡片。
- 工具区区分可配置 MCP 与运行时内置能力。
- 日志区区分会话与工具执行，详细输出按需读取。

## 视觉规范

白色导航与卡片，暖灰背景，以 #FF6A00 为品牌橙。深橙主要操作保证白字可读，浅橙用于选择和聚焦；绿色与红色保留状态和 diff 语义。
使用系统中英文字体，轻边框、圆角、充足留白；不依赖远端字体和图片。
桌面固定左侧导航；平板和手机折叠为菜单，卡片按 4/2/1 列调整，表格局部横向滚动。
编辑采用聚焦弹窗，手机保持可滚动和可关闭；所有按钮、表单与开关有语义标签。

## 交互约定

搜索即输即筛选，空列表有解释；保存有忙碌态、失败原因及成功反馈。
删除和默认模型切换先展示影响再确认。编辑密钥时不显示原值，留空保留。
敏感资源、内置和项目技能只读；公共技能可编辑，修改前提醒跨 Agent 影响。普通列表手动刷新，日志按 15 秒自动刷新。
管理页面不负责偷偷启动工具，也不因保存模型名称就宣称模型可用。

## 模型与配置管理调整

导航将供应商与模型合并为「模型管理」：供应商卡片进入供应商下的模型卡片，
模型卡片进入详情页；常用参数直接编辑，不展示底层 JSON。
最后一项「配置文件」采用编辑器与历史列表双栏布局，窄屏改为上下排列。
版本记录跟随本机配置保存，不依赖浏览器缓存，回滚不覆盖历史。

## 配置工作区交互

移除页面宣传式副标题，只保留标题、状态和必要操作提示。当前配置采用编辑器与
版本侧栏，版本对比占用完整内容宽度。默认只读，编辑后显式保存或取消；草稿和
撤销历史跨页面保留。差异比较支持任意两个版本，默认基准在左、目标在右，红色
表示删除、绿色表示新增；手机可切换行内布局。保存不自动覆盖外部更新。
